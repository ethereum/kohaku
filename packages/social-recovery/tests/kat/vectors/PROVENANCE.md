# Provenance of the blessed vector copies

The copies come from two sources, each listed in its own block below with the
sha256 of every file it supplied. Every copy is a test fixture: it is never
edited, never reformatted and never regenerated by any implementation or
script in this repository. A changed vector arrives only as a fresh byte copy
from its source, and the block that lists it is updated in the same change.
`../provenance.test.ts` fails if a listed file is missing, if its sha256
differs from its block, if a file is listed twice, or if an unlisted `.json`
file sits in this folder.
