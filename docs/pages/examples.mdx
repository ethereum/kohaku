# A real integration

The snippets in this guide are the API. [kohaku-cli](https://github.com/kassandraoftroy/kohaku-cli) is a wallet that calls it: encrypted storage, a viem provider with chunked logs, Tor on `host.network.fetch`, and shield / unshield commands for both protocols.

The CLI also constructs a Railgun plugin in the same files. These pages cover Privacy Pools and Tornado Cash.

## Host

| File | What it shows |
| --- | --- |
| [`src/host/makeHost.ts`](https://github.com/kassandraoftroy/kohaku-cli/blob/main/src/host/makeHost.ts) | Assembles `Host`: viem provider, keystore, encrypted storage, `fetch`, and the Tornado external sync source. |
| [`src/host/keystore.ts`](https://github.com/kassandraoftroy/kohaku-cli/blob/main/src/host/keystore.ts) | `deriveAt` from the wallet mnemonic, plus stealth-account paths. |
| [`src/host/storage.ts`](https://github.com/kassandraoftroy/kohaku-cli/blob/main/src/host/storage.ts) | One encrypted JSON file per plugin (`ppv1-storage.json`, `tc-storage.json`). |
| [`src/host/chunked-get-logs.ts`](https://github.com/kassandraoftroy/kohaku-cli/blob/main/src/host/chunked-get-logs.ts) | Splits `eth_getLogs` when the RPC rejects a wide range. |

## Plugins

[`src/utils/plugins.ts`](https://github.com/kassandraoftroy/kohaku-cli/blob/main/src/utils/plugins.ts) is the integration in one module.

- `createProtocolPlugin` calls `createTCPlugin` and `createPPv1Plugin` with the deployment config, paymaster map, artifacts loader, and saga data source for the chain.
- `prepareProtocolShield` calls `prepareShield`. Tornado passes `DepositStrategy.MinFee`.
- `broadcastTornadoPrivateOp` calls `createTCBroadcaster` and `broadcast`.
