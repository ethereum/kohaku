Add the zkPassport recovery method under the `./recovery-methods` entry: `zkPassportMethod()` returns the `IRecoveryMethod` whose codec reads and writes the `method-zkpassport` config `(bytes32 uniqueIdentifier, string domain, string scope, uint256 validityPeriodInSeconds)` and proof layouts, binds the digest as the request's custom data, and reaches `@zkpassport/sdk` (an optional peer) only through an injectable constructor.

New exports from the `./recovery-methods` entry: `zkPassportMethod`.
