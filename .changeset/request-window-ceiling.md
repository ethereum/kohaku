The client configuration's request window now carries a ceiling, and a request whose window is wider than it warns. New: the required member `RequestWindowBounds.ceiling`, the width above which a request warns, in seconds, which every client build and constructor checks as a non-negative safe integer (a `TypeError` or `RangeError` naming `configuration.requestWindow.ceiling` otherwise; no order between `floor`, `default` and `ceiling` is checked); `BUILDER_REQUEST_WINDOW`, and with it `BUILDER_DEFAULT_CONFIGURATION`, now carries `ceiling: 259200` (72 hours); and the warning code `request.window-wide` (subject `request`, values `window` and `ceiling`, in seconds) in `REQUEST_WARNING_CODES`, before `request.window-short`. It is raised where the window from the pinned block's timestamp to `validUntil` is strictly wider than the ceiling, so a window exactly at it is silent: by `windowFindings`, after any `request.window-short`, and with it by the recovery client's `assess` on both gatherings; and by `validateRequest` on both kinds, against `context.configuration.requestWindow`, measuring the width left at the submission block. `windowFindings` and `validateRequest` throw a `TypeError` or `RangeError` naming `bounds.ceiling` or `context.configuration.requestWindow.ceiling` where it is missing or not a non-negative safe integer. The gathering inits and the prepares do not refuse a wide window, and `submissionFindings` is unchanged.

Breaking: `RequestWindowBounds` gains the required member `ceiling`, so a configuration that sets its own `requestWindow`, which replaces the default's whole record, must add `ceiling`, or the builds, the client constructors, `windowFindings` and `validateRequest` throw; a configuration that leaves `requestWindow` to the default gets 72 hours.

Compatibility: the closed set `REQUEST_WARNING_CODES`, and with it the `WarningCode` union, grew by one member, so a consumer that keeps an exhaustive map or switch over every warning code must add `request.window-wide` before it compiles again; a consumer that reads findings as data is unaffected. A gathering or request whose window is wider than 72 hours under the default configuration, which used to assess and validate silently, now carries the warning; a warning never blocks a prepare.
