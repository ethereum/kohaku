Add `SocialRecoveryBuilder`, the one class that constructs the kit's classes. `SocialRecoveryBuilder.from(inputs)` takes the holder's inputs (`provider` and `account` required; `descriptor`, `chainId`, a partial `configuration` and `deviceBindings` optional) or an approver's inputs (a `descriptor` or a `chainId` and optional `deviceBindings`, no provider and no account); any other own member of either shape throws a `TypeError` naming it, so an approver's inputs carrying a `configuration` are refused. The type parameter defaults to the holder's inputs, so a builder typed plain `SocialRecoveryBuilder` calls every build and an approver's builder is not assignable to it; and `SocialRecoveryBuilder.build(inputs)` is `from(inputs).build()`. The chain id comes from the descriptor, else from the provider; without a descriptor the chain's shipped descriptor is read, and one whose manager is still the zero address refuses. The `with*` calls replace or add parts: `withPolicyManager`, `withEventManager` (an instance or `{ logChunkSize }`), `withRecoveryAction` (an address with an optional part or factory), `withCodec` (an instance or `{ actions }`, adds; either form whose actions are malformed, empty or repeated throws at the call, a malformed list a `TypeError` and an empty or repeated one a `RangeError`; the same instance added again is kept once, and two different codecs serving one action throw a `TypeError` at the first build), `withMethod` (adds; `walletMethod()` and `passkeyMethod()` are registered by default and a zero module is skipped; an added method takes the modules it claims from those two defaults, which keep only the modules no added method claims, and two added methods claiming one module throw a `TypeError`), `withSignerRecovery`, `withVersionEscape`, `withManagerReading`, with `managerReading()` reading the cached manager reading back. The builds `build()`, `buildSetupClient()`, `buildRecoveryClient()`, `recoveryAction()`, `methodModuleReads()` and the synchronous `buildMethodsOrchestrator()` memoize everything they construct. `buildSetupClient()`, `buildRecoveryClient()`, `recoveryAction()` and `methodModuleReads()` run the construction checks on the manager's EIP-712 domain and `version()`, on the first of them to build; `build()` delegates to them and commits nothing until every product it returns is constructed. Every `with*` call throws a `TypeError` after the first successful build, and while a build is still running it throws a `TypeError` with its own message, before it checks its argument; a failed build caches nothing and reopens them. Add `descriptorOriginOf`, and the types `SocialRecoveryHolderInputs`, `SocialRecoveryApproverInputs`, `SocialRecoveryInputs`, `SocialRecoveryKit`, `EventManagerOptions`, `ActionCodecOptions`, `RecoveryActionPart`, `RecoveryActionContext`, `RecoveryActionFactory`, `BuilderEscapedCheck` and `ManagerReading`. New constants: `BUILDER_SEPOLIA_DESCRIPTOR`, `BUILDER_MAINNET_DESCRIPTOR`, `BUILDER_DEFAULT_DESCRIPTORS`, `BUILDER_DEFAULT_CONFIGURATION`, `BUILDER_DEFAULT_WAIT`, `BUILDER_SHORT_WAIT`, `BUILDER_MAX_WAIT`, `BUILDER_REQUEST_WINDOW`, `BUILDER_CANCEL_WINDOW`, `BUILDER_RULE_COST_BOUND`, `BUILDER_BLOCK_TAGS`, `BUILDER_DEFAULT_LOG_CHUNK_SIZE`, `BUILDER_DOMAIN_FIELDS`, `BUILDER_DOMAIN_EXTENSION_BITS`, `BUILDER_ESCAPED_CHECKS`, `BUILDER_POLICY_MANAGER_MEMBERS`, `BUILDER_EVENT_MANAGER_MEMBERS`, `BUILDER_RECOVERY_ACTION_MEMBERS`, `BUILDER_PROVIDER_MEMBERS`, `BUILDER_SIGNER_RECOVERY_MEMBERS`, `BUILDER_EVENT_MANAGER_OPTIONS`, `BUILDER_CODEC_OPTIONS`, `BUILDER_HOLDER_INPUT_MEMBERS`, `BUILDER_APPROVER_INPUT_MEMBERS` and the messages `BUILDER_UNKNOWN_CHAIN_MESSAGE`, `BUILDER_NO_PUBLIC_DEPLOYMENT_MESSAGE`, `BUILDER_CHAIN_MISMATCH_MESSAGE`, `BUILDER_NO_DOMAIN_MESSAGE`, `BUILDER_DOMAIN_CHAIN_MESSAGE`, `BUILDER_VERIFYING_CONTRACT_MESSAGE`, `BUILDER_DOMAIN_FIELDS_MESSAGE`, `BUILDER_DIGEST_VERSION_MESSAGE`, `BUILDER_DOMAIN_NAME_MESSAGE`, `BUILDER_BODY_ENCODER_MESSAGE`, `BUILDER_READING_MISMATCH_MESSAGE`, `BUILDER_VERSION_ESCAPED_MESSAGE`, `BUILDER_FROZEN_MESSAGE`, `BUILDER_PENDING_MESSAGE`, `BUILDER_APPROVER_MESSAGE`, `BUILDER_HOLDER_INPUTS_MESSAGE`, `BUILDER_NO_CHAIN_MESSAGE`, `BUILDER_UNRESOLVED_CHAIN_MESSAGE`, `BUILDER_CHAIN_ID_MISMATCH_MESSAGE`, `BUILDER_MODULE_CLAIMED_MESSAGE` and `BUILDER_ACTION_CLAIMED_MESSAGE`.
