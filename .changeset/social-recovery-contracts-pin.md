Follow the recovery kit's contracts at `defi-wonderland/social-recovery-contracts@0b7073a`. The manager's two owner calls carry a second word: `clearSetup(address action, uint64 nonce)`, selector `0x002a237c`, and `cancelByOwner(address action, uint64 attemptId)`, selector `0x2970c92b`, both in `POLICY_MANAGER_WRITES_ABI`. `SetupClient.prepareClearSetup` names the setup nonce it reads at the pinned block. `RecoveryClient.prepareCancelByOwner()` keeps its signature but now reads the manager's state at one pinned block and names the waiting attempt's id; while no attempt is waiting it throws a `KitRefusalError` carrying `request.no-active-attempt`, before any simulation. `decodeRevert` names two new errors: the manager's `PolicyManager_ActionDoesNotServeAccount(address account, address action)`, selector `0xa1844eb2`, which `commitSetup` raises when the action does not serve the calling account, and the action's `RecoveryAction_AccountNotServed(address account)`, selector `0x3f6b40e3`. The Aadhaar method's config is three words, `abi.encode(uint256 nullifier, uint256 nullifierSeed, uint256 freshnessWindow)`, 96 bytes: `configFrom` writes a fixed window of 86400 seconds; the local verdict rejects a config whose window is under 3600 seconds, the contract's minimum, and a proof that discloses the age, gender, postcode or state input; and `replyFrom` returns `material-rejected` when the QR was signed more than the config's window before the system clock's time. The method event `AdminRenounced` reads `previous` from the topics, as the contracts index it. `validateSetup` raises the error `action.unsupported` whenever the action's `supportsAccount` answers no, since the manager now refuses that commit, and the warning `action.fit-unchecked` is retired.

Breaking: `IPolicyManagerInteractor.prepareClearSetup(action, nonce, block?)` and `prepareCancelByOwner(action, attemptId, block?)` take the new word before the block, and `PolicyManager` implements them so; `SETUP_WARNING_CODES` and `WarningCode` lose `action.fit-unchecked`; an Aadhaar config of 64 bytes no longer decodes.
